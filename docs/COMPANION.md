# LOWTIDE companion (MCP, stage 1)

The companion lets an AI client such as Claude Code read your LOWTIDE project context,
and add notes and session records, through the Model Context Protocol.

It's stage 1 of ADR-040/ADR-055: it serves the **exported workspace**. LOWTIDE's own
records still live in your browser, and the companion can't change them yet.

## 1. Export the workspace

1. In LOWTIDE, open **AI & workspace** (in More on phones).
2. Choose **Export workspace (.zip)**.
3. Unzip it into a folder, for example `~/lowtide-workspace`.

Re-export whenever you want the files updated. Files marked "Generated by LOWTIDE" are
replaced; notes and sessions the companion added are separate files and are kept.

## 2. Start the companion from your AI client

The companion is a Node script. It needs Node 22.18 or later, and nothing else to
install:

```sh
node /path/to/lowtide/companion/lowtide-mcp.ts --workspace ~/lowtide-workspace --project <slug>
```

With Claude Code:

```sh
claude mcp add lowtide -- node /path/to/lowtide/companion/lowtide-mcp.ts \
  --workspace ~/lowtide-workspace --project <slug>
```

- `--project <slug>` (the default and recommended) exposes one project. The slug is
  the folder name under `projects/`.
- `--scope workspace` exposes every project's technical files. Use it only for an
  assistant you want to see all of them.

## Tools

| Tool                                                                                  | Does                                                                                 |
| ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `get_context`                                                                         | the project's CONTEXT.md (start here)                                                |
| `get_project`                                                                         | PROJECT.md: state, milestones, board                                                 |
| `get_project_summary`                                                                 | state, phase, completion, next action, lane counts                                   |
| `get_recent_activity`                                                                 | recent timeline entries                                                              |
| `get_waiting` / `get_approval_requests`                                               | the Waiting and Needs approval lanes                                                 |
| `search_workspace`                                                                    | case-insensitive search of the files in scope                                        |
| `get_document`                                                                        | read one file in scope                                                               |
| `create_note`                                                                         | add `docs/notes/<date>-<title>.md` (never overwrites; audit-logged)                  |
| `log_ai_session`                                                                      | add `ai/sessions/<date>-<client>-….md` (audit-logged; not imported into LOWTIDE yet) |
| `record_decision`, `update_project`, `complete_task`, `request_approval`, `park_item` | **not available yet**: they refuse and change nothing                                |

## Safety

- The companion opens no network port. It talks only to the client that started it.
- It reads and writes only inside the workspace folder; paths and symlinks leading
  outside are refused.
- It only adds files, and logs every write in `.lowtide/audit.log`.
- The workspace never contains protected time, sleep, routines, medication, college
  records or your inbox.
